# 💬 Sentiment Analysis

A Natural Language Processing (NLP) project that classifies text reviews as positive or negative using Python and scikit-learn.

## 🎯 Project Overview

This project demonstrates a basic text-classification workflow by transforming written reviews into numerical features and using machine learning to predict sentiment.

## ⚙️ Project Workflow

- Load and inspect text-review data
- Prepare text for analysis
- Convert text into numerical features using TF-IDF
- Train a classification model
- Predict positive or negative sentiment
- Evaluate model performance

## 🛠 Technologies Used

- Python
- scikit-learn
- Natural Language Processing (NLP)
- TF-IDF
- Jupyter Notebook

## 🧠 Method

### TF-IDF

TF-IDF converts text into numerical feature vectors based on the importance of words within the dataset. These features can then be used by a machine-learning classifier.

## 📊 Results

The project demonstrates an end-to-end introductory NLP workflow for classifying text sentiment.
